# 🎮 Cracked the Code of Counter-Strike Gameplay with Machine Learning! 🔥 (85%+ Accuracy)

# 🔍 Project Title:
Predictive Modeling on Counter-Strike Gameplay using Machine Learning (Classification)

Recently, I worked on a high-impact machine learning project focused on analyzing gameplay data from one of the most iconic esports titles – Counter-Strike. The dataset was massive, comprising 100,000+ rows and over 90 gameplay-related features, ranging from player performance metrics to in-game actions and map dynamics.

# 📌 Key Milestones in the Project:

✅ Exploratory Data Analysis (EDA):
Conducted deep analysis to understand gameplay patterns, player behaviors, and influential features. This helped identify key performance indicators and trends within the game mechanics.

✅ Data Cleaning & Preparation:

Implemented Label Encoding to handle numerous categorical features (e.g., weapon types, player roles, map names).

Dealt with missing values, scaled the data, and prepped it for modeling.

✅ Dimensionality Reduction with LDA (Linear Discriminant Analysis):

Took a unique approach by applying LDA in a strategic and unconventional manner, not just for dimensionality reduction but to enhance class separation, helping the models better understand the distinctions between different gameplay outcomes.

✅ Model Development & Evaluation:

🌳 Decision Tree Classifier
